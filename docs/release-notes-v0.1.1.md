# v0.1.1 — 动效与玻璃质感

这一版不动功能，只做界面：一套统一的动效语言，和一次大幅度的性能瘦身。

## 动效

- 全部过渡改用 Apple 那套缓动曲线 `cubic-bezier(0.32, 0.72, 0, 1)`，三档时长 140 / 220 / 320ms
- 页面切换淡入淡出，不再是硬切
- 侧栏选中项、按钮悬停、卡片抬升统一节奏
- 任务栏进度条从跳变改成平滑插值
- 系统开启「减少动效」时，全部动效自动降级为无

## 玻璃质感

- 侧栏和首页启动大卡是真玻璃：`backdrop-filter: blur() saturate()`
- 镜面边缘：顶部 1px 高光 + 四周渐变描边，玻璃才有厚度
- 静态噪点层（纯白颗粒，SVG 生成），消除大面积半透明常见的脏灰感
- 卡片底色半透明，能看见背后背景的颜色

## 性能

上一个大版本的玻璃是「哪里都糊」，这一版砍到只剩视觉焦点：

| 项 | 之前 | 现在 |
|---|---|---|
| 首页模糊层数 | 9 层 | **2 层**（侧栏 + 启动大卡） |
| 设置页模糊层数 | 6 层 | **1 层**（只有侧栏） |
| 模糊半径 | 20–24px | **12–14px** |
| 无限循环动画 | 1 个（48s 背景漂移） | **0** |
| 高光扫过写法 | `background-position`（触发重绘） | `transform`（合成器处理） |

模糊的采样面积和半径的平方成正比，20px 降到 12px 单层开销就少约 64%；层数再减掉 7 层，合计大约降到原来的 **1/12**。

背景漂移动画是最大的那笔开销 —— 它每帧重绘背景，导致所有模糊层每帧重新采样。删掉之后即使低配机器也不会再有持续的渲染负载。

## 界面

- **关于页重做**：版本号、Java 运行环境、数据目录、更新检查集中在一处，状态一眼可见
- 设置页打开时静默检查更新，有新版才提示，不打扰
- 首页账户按钮：令牌过期时自动续期并刷新显示

## 修复

- 深色主题下首页快捷卡片白底白字（硬编码了浅色背景）
- 大屏 / 全屏时内容没有跟着放大（布局上限写死了 1000px）

## 安装

下载 `MC Launcher_0.1.1_x64-setup.exe`，双击安装。
默认装到当前用户目录，**不需要管理员权限**。覆盖安装会保留原有配置和实例。

## 已知问题

- **没有代码签名**：Windows SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」即可。
- 更新检查只**提示**新版本，不会自动下载安装。
- 还没做模组加载器（Fabric / Forge 等），只能装原版。
