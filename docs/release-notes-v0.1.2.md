# v0.1.2 — 启动器能自己更新了

这一版把「发现新版只能跳网页」变成了「点一下直接装好」。

## 自动更新

设置页的「关于」区域现在是这样工作的：

1. 进设置页就静默检查一次，不打扰
2. 有新版本 → 按钮直接变成「安装更新」
3. 点下去：下载（带百分比进度条）→ 校验签名 → 启动 Windows 安装程序
4. 安装程序以 passive 模式运行，不需要点下一步
5. 装完重开启动器就是新版

**安全**：更新包用 Ed25519 签名，客户端内置公钥验证。如果包被篡改或者不是同一把私钥签的，安装会被直接拒绝。这个是 Tauri updater 的强制机制，关不掉。

**兜底**：如果官方 updater 走不通（网络策略、企业代理等），会自动回落到原来的 GitHub Release 检查，至少还能给出跳转链接。

## 底层改动

- 接入 `tauri-plugin-updater` 2.14 + `tauri-plugin-process` 2.4
- 构建时用 `createUpdaterArtifacts` 生成 `.sig` 签名
- CI 每次发版自动生成 `latest.json`，内容包括版本号、安装包地址、签名
- 私钥存在 GitHub Secret 里，永不出现在代码或日志中

## 安装

下载 `MC.Launcher_0.1.2_x64-setup.exe`，双击安装。

**已经在用 0.1.1 的话**：进设置页 → 「安装更新」即可，不用手动下载。

## 已知问题

- **没有代码签名**：Windows SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」即可。（updater 的签名是给更新包校验用的，不是 Windows 代码签名证书）
- 还没做模组加载器（Fabric / Forge 等），只能装原版。
